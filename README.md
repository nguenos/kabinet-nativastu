# Личный кабинет Nati Vastu

Личный кабинет для учениц: вход по коду на email, купленные продукты, доступ к гайдам,
автоматическая выдача доступа после оплаты через Prodamus.

## Что уже работает (MVP, шаг 1)

- Вход по email-коду (без пароля, без SMS).
- Кабинет с карточками продуктов: купленное отдельно, доступное к покупке отдельно.
- Прогресс по каждому материалу.
- Гайды спрятаны за вход: открыть может только тот, кто вошёл и у кого есть покупка.
- Вебхук Prodamus: после успешной оплаты доступ выдаётся сам.

## Запуск на своём компьютере

```bash
cd kabinet-nativastu
npm install
npm run seed      # демо-ученица demo@nativastu.com с тремя покупками
npm start         # откроется на http://localhost:3000
```

Зайдите на http://localhost:3000, введите `demo@nativastu.com`.
В демо-режиме код показывается прямо на экране (почтовый сервер ещё не подключён).

## Структура

```
server.js            маршруты: вход, кабинет, гайды, вебхук
src/db.js            хранилище (JSON) + каталог продуктов
src/auth.js          сессия в cookie, вход
src/mailer.js        отправка кода (dev: в консоль, prod: SMTP)
src/prodamus.js      проверка подписи и разбор оплаты
public/              login.html, app.html, тема, шрифты
guides/              гайды-страницы за входом (ваши файлы)
data/db.json         данные (создаётся автоматически)
```

## Каталог продуктов

Правится в `src/db.js`, массив `products`. Поля: id, title, type, desc, cover (g1..g4), sym, slug, price.
`slug` должен совпадать с именем файла в `guides/` (например `elements-cleaning` → `guides/elements-cleaning.html`).

## Переменные окружения (для продакшена)

| Переменная | Зачем |
|---|---|
| `SESSION_SECRET` | секрет для подписи входа (любая длинная строка) |
| `NODE_ENV=production` | включает Secure-cookie |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` | реальная отправка кода на email |
| `PRODAMUS_SECRET` | секрет для проверки подписи вебхука Prodamus |

Пока `SMTP_*` не заданы, код входа показывается на экране (демо).
Пока `PRODAMUS_SECRET` не задан, подпись вебхука не проверяется (только для теста).

## Подключение Prodamus (шаг 3)

1. В настройках платёжной формы Prodamus укажите URL уведомлений:
   `https://ВАШ-ДОМЕН/webhook/prodamus`
2. Возьмите секретный ключ из Prodamus и задайте его в `PRODAMUS_SECRET`.
3. Чтобы кабинет понимал, какой продукт оплачен, передавайте в заказе параметр
   `nv_product` со значением id продукта (например `clean5`), либо сопоставьте
   названия товаров в `src/prodamus.js` (PRODUCT_MAP).

## Деплой на Render (как в примере)

1. Залейте папку в репозиторий GitHub.
2. Render → New → Web Service → выберите репозиторий.
3. Build command: `npm install` · Start command: `npm start`.
4. Задайте переменные окружения из таблицы выше.
5. Подключите поддомен, например `lk.nativastu.com`, в настройках Render + DNS.
